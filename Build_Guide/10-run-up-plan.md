# Run-up plan

*From today to submission, with the moment each decision has to be made.*

- **This week:** Every team member registers an Earthdata Login account and collects a FIRMS MAP_KEY, a free api.nasa.gov key and an ADS token. Test each with a single call. Fork the repository template with `CLAUDE.md`, `AGENTS.md` and the skill folders already in it.
- **By 1 Oct:** Shortlist two or three challenges from the summaries. Record and upload the 240-second prescreening video — concept only is what the form asks for at this stage.
- **28 Oct:** Full challenge statements land. In one sitting, compare NASA's named datasets against the recommendations in this guide, update your data plan and lock scope. If NASA names a dataset you have not cached, caching it is that day's only job.
- **2–12 Nov:** Pre-build `cache/` and `demo_fixtures/`. Wire one MCP server and the relevant skill. Rehearse the demo with wifi disabled. The deadline that matters: a full dry run must succeed offline by 12 November.
- **13 Nov:** Global Offers, the Project Submission Guide and the Judging & Awards Guide all publish. Claim any free credits and align your AI-disclosure text with the official wording.
- **Day one:** Follow the challenge's 48-hour plan. Registration 07:00, opening ceremony 10:30, first mentor round 11:30. The 240-second local judging upload is due at 18:30.
- **Day two, noon:** Freeze features. The last four hours are for the videos, the project page and the public repository — nothing else. If the killer demo is not reproducible offline by now, ship the fixture version and say so.

## What to do when you are behind

Every challenge page has a cut list. The order is always the same: drop the geographic scope first, then the time range, then the interactivity, then the live query. Keep the killer demo moment intact to the very end — it is the only thing a judge will remember, and a project that does one thing convincingly outscores one that half-does five.
