## 1. Official AI Disclosure Overview

In compliance with NASA Space Apps Challenge guidelines on the ethical, transparent, and responsible use of Artificial Intelligence (AI), this document details all AI tools, models, and agents utilized during the ideation, design, development, and narration phases of **Hritu**.

We believe in radical transparency: **AI was used as an engineering accelerant and natural language narrator, but never as an unconstrained decision-maker or scientific compute engine.**

## 3. Strict Compute Boundary: What AI Did NOT Do

To maintain scientific validity (a 20-point judging criterion), we enforced an **impenetrable boundary** between statistical computation and AI:

1. **Zero Hallucination Mathematics:**  
   No LLM computed any p-value, Theil-Sen slope, Kendall's tau, Mann-Kendall S statistic, variance correction factor, or Pettitt change-point. All mathematical models reside in [`src/compute/trend.py`](../src/compute/trend.py) as pure, deterministic Python functions.
2. **Scientific Formulation:**  
   The decision to use the **Hamed & Rao (1998) Modified Mann-Kendall** variance correction (to account for climate lag-1 serial autocorrelation) was an intentional scientific design choice by the team, not generated by an AI.
3. **Thresholds & Algorithms:**  
   The $14^\circ\text{C}$ winter cold day threshold, the 7-day rolling window $>25\text{ mm/day}$ monsoon onset algorithm, and the 95th percentile coastal extreme event cutoffs were researched, selected, and implemented by team members.
4. **Geographic Scoping:**  
   Centroid mapping of Bangladesh's 64 districts and the regional framing of Rajshahi, Sylhet, Bhola, and Dhaka were chosen by the team based on real-world local vulnerabilities.

## 4. The In-App Explanation Agent & Provenance Gate

For the in-app AI narration feature, we implemented an automated verification protocol:

```
Deterministic Compute (src/compute/trend.py)
                   │
                   ▼ (Strict JSON output)
           cite_check Validator
                   │
           ┌───────┴───────┐
      Pass │               │ Fail
           ▼               ▼
Explanation Agent     Block Output & Display
(Claude API Prompt)   "⚠️ Citation Required"
           │
           ▼
Bilingual Narration (English + Bangla) + Clickable NASA Provenance Drawer
```

### Constraints Applied to the Explanation Agent:
- Must only receive pre-computed JSON fields (`p_value`, `slope_per_decade`, `dataset_id`, `source_url`, `district`, `metric`).
- Forbidden from asserting direct causation (limited to describing statistically significant correlation).
- Forbidden from inventing numbers or extrapolating beyond the dataset period.
- Output is verified before presentation via the `cite_check` schema.

The complete system prompt for the Explanation Agent is preserved in [`src/agents/prompts/explain.md`](../src/agents/prompts/explain.md).

**Core System Directive:**
> *"You are the Explanation Agent for Hritu. You translate computed trend JSON into a clear 2-sentence plain-language caption in both English and Bangla. You receive ONLY the JSON result from src/compute/trend.py. You may NOT extrapolate, diagnose causation, or invent numbers. Every claim must link directly to the source NASA dataset ID and URL."*
